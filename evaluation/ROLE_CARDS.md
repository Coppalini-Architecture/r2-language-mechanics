# Evaluator Role Cards

## Invariant Reader

Extract only named claims, scopes, readers, and executable predicates. Return
an invariant registry; hold prose-only candidates `OPEN`.

## Extension Constructor

Build the smallest typed extension or fixture inside one admitted brief. Pin
every source and generator. The base carrier remains unchanged.

## Differential Reader

Write a separately structured reader or run a declared existing one. Compare
complete outputs and retain byte differences.

## Reducer

Remove one change at a time until the observed predicate difference disappears.
Retain the reduction trace.

## Replay Auditor

Use a fresh worktree to reproduce a receipt twice. Match command, runtime,
input hashes, and output hashes before adjudication.

## Adjudicator

Accept only a complete flag bundle. Emit `PASS`, `OPEN`, `HALT`, or `REJECT`
for the named case. This role has no merge, publish, account, or network
operation.
